DRIVGCELL - PORTFOLIO WEB

1) Crear un repositorio PUBLICO en GitHub llamado: drivgcell-portfolio
2) Subir index.html a la raiz del repositorio.
3) Ir a Settings > Pages.
4) En Build and deployment elegir Deploy from a branch.
5) Seleccionar branch main y carpeta /(root), luego Save.
6) Esperar a que GitHub publique el sitio. URL prevista:
   https://ivgsistemas.github.io/drivgcell-portfolio/

IMPORTANTE: Antes de publicar, agregar el WhatsApp correcto en la sección de contacto. El sitio no anuncia stock confirmado: presenta la provisión como modalidad por pedido.
